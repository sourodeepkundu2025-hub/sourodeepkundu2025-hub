# Visuals and evidence sources

Every figure is either original editorial vector work, a diagram of inspected public code, a chart derived from a saved experiment, or an actual browser screenshot. None is a photo of hardware, clinical validation or an employer system. Assets are hosted in this repository; the small technology-icon strip is the only externally loaded artwork and has a text fallback.
